# ArchiVarious

**Развитие проекта: ETL-контейнер знаний.** Добавлен первый конвейер PDF →
текст по страницам → конспект с проверяемыми цитатами. Пока запускается отдельно
через CLI: [инструкция и ограничения](docs/ETL.md). Без выбора модели извлечение
работает локально; синтез требует настройки AI Gateway. Видео, аудио и другие
форматы запланированы, но ещё не поддерживаются этим конвейером.

Быстро запишите то, что нужно запомнить. ArchiVarious слегка отформатирует запись, а спустя какое-то время задаст короткий опрос из трёх вопросов и с помощью своего алгоритма разложит заметку по вашему «второму мозгу» в Obsidian.

Проект состоит из двух продуктов:

- **Плагин Obsidian** (`apps/obsidian-plugin`) для десктопа и мобильных.
- **Виджет-приложение** (`apps/widget`) на Tauri 2 для Windows, macOS, Linux, Android и iOS: на рабочем столе Windows 11 это постоянная строка ввода, в которой запись можно сразу разложить или отправить в Google Календарь. Вызов: `Ctrl/⌘+Shift+Space` или значок в трее.

Архитектура и обоснование каждого решения описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

Готовые файлы лежат в [Releases](https://github.com/maksimka208151-eng/ArchiVarious/releases): плагин публикуется под тегом вида `0.1.0`, виджет под тегом вида `widget-v0.4.0`. Берите самую свежую версию.

### Плагин Obsidian на Windows: установщик

1. Скачайте из релиза плагина файл `ArchiVarious-installer.exe` и запустите его.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»** (установщик пока не подписан).
3. В окне выберите хранилище Obsidian (они находятся сами, свою папку можно указать кнопкой «Другая папка…») и нажмите **«Установить»**. Если Obsidian открыт, установщик попросит его закрыть.
4. Установщик скопирует плагин в `<хранилище>/.obsidian/plugins/archivarious` и включит его. Заметки и настройки плагина не меняются, так что так же можно обновлять плагин.
5. Откройте хранилище. Если Obsidian спросит, доверяете ли вы автору хранилища, выберите вариант с включением плагинов.

### Плагин Obsidian вручную (macOS, Linux или без установщика)

1. Скачайте из релиза плагина `archivarious-plugin.zip` (или три файла: `main.js`, `manifest.json`, `styles.css`). Архив с исходниками (`Source code`, после распаковки папка `ArchiVarious-main`) для установки не нужен.
2. В Obsidian откройте **Настройки → Сторонние плагины** и при необходимости выключите **Безопасный режим**.
3. Нажмите на значок папки рядом с «Установленные плагины», откроется `<хранилище>/.obsidian/plugins`.
4. Положите туда папку `archivarious` из архива (или создайте её и положите в неё три файла). Должно получиться `<хранилище>/.obsidian/plugins/archivarious/main.js`.
5. Обновите список плагинов и включите **ArchiVarious**.

### Плагин Obsidian (телефон)

- Если хранилище синхронизируется (Obsidian Sync, iCloud, Syncthing), установите плагин на компьютере и включите в синхронизации пункт «Установленные плагины».
- Без синхронизации скопируйте папку `archivarious` в `<хранилище>/.obsidian/plugins/` через файловый менеджер (папка `.obsidian` скрытая).

### Виджет для Windows 11

1. Скачайте из релиза виджета `ArchiVarious_<версия>_x64-setup.exe` (или `.msi`) и запустите.
2. Приложение пока не подписано, поэтому Windows может его остановить:
   - окно SmartScreen «Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**;
   - если кнопки «Выполнить в любом случае» нет, установку блокирует **Smart App Control**. Его можно выключить в **Безопасность Windows → Управление приложениями и браузером → Параметры Smart App Control**, но включить обратно получится только переустановкой Windows.
3. При первом запуске нажмите «Выбрать…», укажите папку хранилища Obsidian (ту, где лежит `.obsidian`) и нажмите «Готово».

Для macOS и Linux в том же релизе есть `.dmg`, `.AppImage`, `.deb` и `.rpm`, но на настоящих машинах они не проверялись.

## Возможности

- **Быстрая запись** в Obsidian, в строке на рабочем столе Windows или из ярлыка (`obsidian://archivarious?text=…`). Текст слегка форматируется, теги вида `#книги` подхватываются автоматически.
- **Отложенный опрос из трёх вопросов:** раздел, что это (факт, идея, задача, материал) и насколько важно. После ответа заметка переезжает в выбранную папку.
- **Разложить сразу**, не дожидаясь опроса.
- **Свои разделы и подразделы**, которые предлагаются в каждом опросе.
- **Связи в графе:** разложенная заметка получает ссылки на похожие заметки и на заметку-оглавление своей папки.
- **Пересмотр спустя время:** заметка возвращается с тем же опросом через 7 дней, важные возвращаются снова со всё большим интервалом.
- **Алгоритм учится** на ваших ответах и с каждым разом точнее подсказывает папку. Всё работает локально, без облака и аккаунтов.
- **Задача в Google Календарь:** переключатель «Заметка / Задача в календарь» создаёт событие на выбранные дату и время.

## Как пользоваться

### В Obsidian

- **Записать:** значок ArchiVarious (логотип) на левой панели или команда **ArchiVarious: Quick capture** (её можно повесить на горячую клавишу). `Ctrl/⌘+Enter` сохраняет во «Входящие» (`ArchiVarious/Inbox`), «Разложить сейчас» (`Ctrl/⌘+Shift+Enter`) сразу открывает опрос.
- **Опрос** приходит сам примерно через 6 часов после записи (тихие часы с 23:00 до 8:00 пропускаются). «Позже» откладывает его.
- **Команды** (палитра `Ctrl/⌘+P`, начните вводить «ArchiVarious»):

| Команда | Что делает |
|---|---|
| Quick capture | Окно быстрой записи |
| Sort all inbox captures now | По очереди разобрать всё, что лежит во «Входящих» |
| Sort due captures now | Разобрать только те записи, чей опрос уже наступил |
| Review earlier notes now | Пересмотреть все разложенные заметки сразу, не дожидаясь срока |
| Sort current note | Разложить открытую заметку, даже созданную до плагина |
| Edit sections | Открыть список своих разделов |

- **Правый клик по файлу → ArchiVarious: разложить** раскладывает любую заметку.
- **Настройки плагина:** папка входящих, папка по умолчанию, задержка опроса, срок пересмотра («Review after», 0 выключает пересмотр), ссылка на оглавление папки и Google Календарь.

### Свои разделы и подразделы

- В опросе первая строка называется **«Раздел»**, вторая **«Подраздел»**. Кнопка **«+ раздел»** создаёт раздел (папку), например «Учеба». Кнопка **«+ подраздел»** создаёт папку внутри выбранного раздела, например «Учеба/Математика». Введите название и нажмите `Enter`.
- Созданные разделы остаются навсегда и предлагаются в каждом опросе, и в Obsidian, и в виджете, даже пока в них нет заметок. Подсказки алгоритма стоят первыми.
- Список хранится в заметке `ArchiVarious/Разделы.md` (команда **Edit sections**). Каждый пункт списка — раздел, вложенный пункт — подраздел. Его можно править вручную.

### Задача в Google Календарь

В окне записи есть переключатель **«Заметка / Задача в календарь»** (в виджете это две иконки: листок и календарь). В режиме календаря появляются дата, время и длительность (или галочка «весь день»). Кнопка «В календарь» (в виджете `Enter`) сразу создаёт событие в основном календаре вашего аккаунта Google. Если в тексте есть «завтра в 15:00», «25.10 в 9:30» или «в 7 вечера», дата и время подставятся сами, но их можно поменять. Задача, отправленная в календарь, в хранилище не сохраняется.

**Привязка календаря** (один раз, около 5 минут). Событие создаёт маленький скрипт Google Apps Script в вашем собственном аккаунте Google, поэтому не нужны ни проект в Google Cloud, ни сервер, ни подписка.

1. В Obsidian: **Настройки → ArchiVarious → Google Календарь → «Скопировать скрипт»**. В скрипт уже вписан ваш секретный ключ.
2. Откройте [script.google.com](https://script.google.com) → **«Новый проект»**, удалите всё, что там написано, вставьте скрипт и сохраните (💾).
3. **«Начать развертывание» → «Новое развертывание»**, затем шестерёнка рядом с «Выберите тип» → **«Веб-приложение»**.
4. Укажите «Выполнять как»: **«От моего имени»**, «У кого есть доступ»: **«Все»**. Нажмите **«Начать развертывание»**.
5. Разрешите доступ к календарю своему аккаунту. Если Google пишет, что приложение не проверено: **«Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → «Разрешить»**. Это ваш собственный скрипт.
6. Скопируйте **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`) и вставьте его в настройках плагина в поле **«Адрес веб-приложения»**. Если поле стало красным, адрес скопирован не целиком.
7. Проверьте: переключите окно записи на «Задача в календарь», напишите «тест завтра в 10:00» и нажмите «В календарь».

Виджет берёт адрес и ключ из настроек плагина сам. Если плагина в этом хранилище нет, настройте виджет: шестерёнка → «Google Календарь» → «Скопировать скрипт», дальше те же шаги, и вставьте адрес в поле рядом.

Доступ «Все» нужен, чтобы ArchiVarious мог достучаться до скрипта. Без вашего ключа скрипт ничего не создаёт, а адрес знаете только вы. Ошибка «неверный ключ» значит, что скрипт скопирован из другого места (например, из виджета, а адрес вставлен в плагин): скопируйте скрипт заново там, где вставляете адрес, и обновите его на script.google.com (**«Управление развертываниями» → ✏️ → «Новая версия»**).

### Виджет на рабочем столе Windows

- Строка лежит на рабочем столе под окнами. `Ctrl+Shift+Space` или клик по значку в трее выводит её вперёд, и она остаётся поверх окон, пока вы не нажмёте `Esc` или снова `Ctrl+Shift+Space`.
- `Enter` сохраняет во «Входящие» (опрос придёт позже в Obsidian), `Ctrl+Enter` или кнопка с молнией сразу показывает опрос прямо в виджете, с теми же разделами и подразделами. `Shift+Enter` переносит строку.
- Переключатель с иконками листка и календаря меняет режим «Заметка / Задача в календарь».
- Панель перетаскивается за логотип слева. Под шестерёнкой настройки: папка хранилища, режим «На рабочем столе, под окнами» или «Поверх всех окон», запуск вместе с Windows, Google Календарь. Выход через меню значка в трее (правый клик → «Выход»).
- Виджет берёт из плагина папку входящих, сроки опроса и пересмотра и настройку календаря. Подсказки папок он строит по хранилищу сам, Obsidian при этом может быть закрыт.

### Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Окно записи в Obsidian | `Ctrl/⌘+Enter` | Сохранить (в режиме календаря: в календарь) |
| Окно записи в Obsidian | `Ctrl/⌘+Shift+Enter` | Сохранить и сразу разложить |
| Везде в Windows | `Ctrl+Shift+Space` | Показать или убрать виджет |
| Виджет | `Enter` / `Ctrl+Enter` | Во «Входящие» (или в календарь) / разложить сейчас |
| Виджет | `Esc` | Убрать виджет на рабочий стол |
| Опрос | `Enter` / `Esc` | Разложить / позже |

## Для разработчиков

### Структура

```
packages/core            логика без зависимостей: формат, планировщик опроса, алгоритм размещения, протокол «Входящих»
packages/ui              общий Svelte-компонент быстрого ввода
apps/obsidian-plugin     плагин Obsidian (esbuild)
apps/widget              виджет-приложение (Vite + Svelte + Tauri 2 / Rust)
apps/installer           установщик плагина для Windows (Go, один exe без зависимостей)
docs/                    архитектура и решения
```

### Быстрый старт

Нужны Node 22+, pnpm 10 (`corepack enable`) и, для виджет-приложения, Rust stable и [системные зависимости Tauri](https://tauri.app/start/prerequisites/).

```bash
pnpm install
pnpm check                 # линт + типы + тесты

# Собрать плагин из исходников: появятся apps/obsidian-plugin/{main.js,manifest.json,styles.css}
pnpm build:plugin

# Плагин: пересборка на лету с копированием в тестовое хранилище
OBSIDIAN_VAULT=~/Obsidian/Dev pnpm dev:plugin
# затем в Obsidian: Настройки → Сторонние плагины → включить ArchiVarious

# Установщик плагина для Windows (нужен Go, см. apps/installer/go.mod; собирается на любой ОС):
# apps/installer/dist/ArchiVarious-installer.exe со встроенным плагином из build:plugin
pnpm build:installer

# Виджет-приложение (десктоп)
pnpm dev:widget

# Мобильные (нужны Android SDK / Xcode)
pnpm --filter @archivarious/widget tauri android init
pnpm --filter @archivarious/widget tauri android dev
```

### Релизы

- **Плагин.** `cd apps/obsidian-plugin && pnpm version X.Y.Z --no-git-tag-version` обновит `manifest.json` и `versions.json` (здесь и в корне). После коммита поставьте тег `X.Y.Z`: CI соберёт черновик релиза с тремя файлами плагина, архивом `archivarious-plugin.zip` и установщиком `ArchiVarious-installer.exe`. Черновик нужно опубликовать на GitHub, иначе его видят только владельцы репозитория.
- **Виджет-приложение.** Тег `widget-vX.Y.Z` запускает сборку установщиков для macOS, Windows и Linux (тоже черновиком). Версию виджета меняйте в `apps/widget/package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`.
