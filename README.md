# ArchiVarious

Быстро запишите то, что нужно запомнить. ArchiVarious слегка отформатирует запись, а спустя какое-то время задаст короткий опрос из трёх вопросов и с помощью своего алгоритма разложит заметку по вашему «второму мозгу» в Obsidian.

Проект состоит из двух продуктов:

- **Плагин Obsidian** (`apps/obsidian-plugin`) для десктопа и мобильных.
- **Виджет-приложение** (`apps/widget`) на Tauri 2 для Windows, macOS, Linux, Android и iOS: на рабочем столе Windows 11 это постоянная строка ввода, в которой запись можно сразу разложить (`Ctrl+Enter`). Вызов: `Ctrl/⌘+Shift+Space` или значок в трее.

Архитектура и обоснование каждого решения описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

Готовые файлы лежат в [Releases](https://github.com/maksimka208151-eng/ArchiVarious/releases): плагин публикуется под тегом вида `0.1.0`, виджет под тегом `widget-v0.2.1`.

### Плагин Obsidian (компьютер)

1. Скачайте из релиза плагина три файла: `main.js`, `manifest.json`, `styles.css`. Архив с исходниками (`Source code`, после распаковки папка `ArchiVarious-main`) для установки не нужен.
2. В Obsidian откройте **Настройки → Сторонние плагины** и при необходимости выключите **Безопасный режим**.
3. Нажмите на значок папки рядом с «Установленные плагины», откроется `<хранилище>/.obsidian/plugins`.
4. Создайте там папку `archivarious` и положите в неё три файла. Должно получиться `<хранилище>/.obsidian/plugins/archivarious/main.js`.
5. Обновите список плагинов и включите **ArchiVarious**.

### Плагин Obsidian (телефон)

- Если хранилище синхронизируется (Obsidian Sync, iCloud, Syncthing), установите плагин на компьютере и включите в синхронизации пункт «Установленные плагины».
- Без синхронизации скопируйте папку `archivarious` в `<хранилище>/.obsidian/plugins/` через файловый менеджер (папка `.obsidian` скрытая).

### Виджет для Windows 11

1. Скачайте из релиза виджета `ArchiVarious_<версия>_x64-setup.exe` (или `.msi`) и запустите.
2. Приложение пока не подписано, поэтому Windows может его остановить:
   - окно SmartScreen «Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**;
   - если кнопки «Выполнить в любом случае» нет, установку блокирует **Smart App Control**. Его можно выключить в **Безопасность Windows → Управление приложениями и браузером → Параметры Smart App Control**, но включить обратно получится только переустановкой Windows.
3. При первом запуске нажмите «Выбрать…», укажите папку хранилища Obsidian (ту, где лежит `.obsidian`) и нажмите «Готово».

Для macOS и Linux в том же релизе есть `.dmg`, `.AppImage`, `.deb` и `.rpm`, но на настоящих машинах они не проверялись.

### Как пользоваться

- **В Obsidian:** значок мозга слева или команда **ArchiVarious: Quick capture**. `Ctrl/⌘+Enter` сохраняет во «Входящие» (`ArchiVarious/Inbox`), «Разложить сейчас» (`Ctrl/⌘+Shift+Enter`) сразу открывает опрос. Без этого опрос появится примерно через 6 часов. Разложенные заметки возвращаются на пересмотр через 7 дней, любую заметку можно разложить через правый клик → **ArchiVarious: разложить**.
- **Свои разделы:** в опросе кнопка «+ раздел» создаёт раздел (папку), например «Учеба», а «+ подраздел» создаёт папку внутри выбранного раздела. Созданные разделы предлагаются в каждом опросе, и в плагине, и в виджете. Список хранится в заметке `ArchiVarious/Разделы.md`, её можно править вручную (команда **ArchiVarious: Edit sections**).
- **Виджет:** строка лежит на рабочем столе под окнами. `Ctrl+Shift+Space` или клик по значку в трее выводит её вперёд, и она остаётся поверх окон, пока не нажмёте `Esc` или снова `Ctrl+Shift+Space`. `Enter` сохраняет во «Входящие», `Ctrl+Enter` или ⚡ раскладывает сразу. Перетаскивается за ⋮⋮, настройки под ⚙, выход через меню значка в трее.

## Для разработчиков

### Структура

```
packages/core            логика без зависимостей: формат, планировщик опроса, алгоритм размещения, протокол «Входящих»
packages/ui              общий Svelte-компонент быстрого ввода
apps/obsidian-plugin     плагин Obsidian (esbuild)
apps/widget              виджет-приложение (Vite + Svelte + Tauri 2 / Rust)
docs/                    архитектура и решения
```

### Быстрый старт

Нужны Node 22+, pnpm 10 (`corepack enable`) и, для виджет-приложения, Rust stable и [системные зависимости Tauri](https://tauri.app/start/prerequisites/).

```bash
pnpm install
pnpm check                 # линт + типы + тесты

# Собрать плагин из исходников: появятся apps/obsidian-plugin/{main.js,manifest.json,styles.css}
pnpm build:plugin

# Плагин: пересборка на лету с копированием в тестовое хранилище
OBSIDIAN_VAULT=~/Obsidian/Dev pnpm dev:plugin
# затем в Obsidian: Настройки → Сторонние плагины → включить ArchiVarious

# Виджет-приложение (десктоп)
pnpm dev:widget

# Мобильные (нужны Android SDK / Xcode)
pnpm --filter @archivarious/widget tauri android init
pnpm --filter @archivarious/widget tauri android dev
```

### Релизы

- **Плагин.** `cd apps/obsidian-plugin && pnpm version X.Y.Z --no-git-tag-version` обновит `manifest.json` и `versions.json` (здесь и в корне). После коммита поставьте тег `X.Y.Z`: CI соберёт черновик релиза с тремя файлами плагина. Черновик нужно опубликовать на GitHub, иначе его видят только владельцы репозитория.
- **Виджет-приложение.** Тег `widget-vX.Y.Z` запускает сборку установщиков для macOS, Windows и Linux (тоже черновиком). Версию виджета меняйте в `apps/widget/package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`.
